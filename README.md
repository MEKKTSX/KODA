# KODA Intelligence

AI-powered market and portfolio tracker.

## UI v2 (Business)

Branch `feature/ui-v2-business` introduces a light professional theme with hybrid layout:

- **Desktop (≥1024px):** fixed sidebar navigation
- **Mobile:** bottom tab bar
- Shared design system: `css/koda-tokens.css`, `css/koda-shell.css`, `js/tailwind-config.js`, `js/layout.js`

See `docs/design-spec-v2.md`, `docs/ui-dom-contract.md`, and `docs/qa-v2.md`.

## Run locally

Serve the project root with any static server (e.g. `npx serve .`) and open `index.html`. API routes require Vercel deployment or compatible serverless setup.
